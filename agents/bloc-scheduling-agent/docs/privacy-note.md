# Privacy Note

This agent manages a real personal calendar across real accounts, relationships, and commitments. Per personal privacy preference, the following are anonymized throughout this public repository:

- Account email addresses → referred to generically as "Personal Account," "Business Account," "Community Project Account"
- Named individuals tied to relationship-time sub-calendars → referred to as "Contact A" / "Contact B," with no location information
- The specific community/creative project's name and tagline → referred to by functional domain ("community events and arts coordination")
- Specific client names appearing in business-account calendar routing → referred to generically as "client work"

Domain categories (client work, relationship time, gym, deep work, job search, admin, community project) are preserved as-is, since the priority-routing logic across these categories is the actual technical and product content being demonstrated — only the identifying specifics behind each category are removed.

All architectural decisions, technical constraints, metrics, and the documented known issues are real and unaltered.
